Adrenaline Quirks — Round 2

Six more ideas. Different angle from the first batch. Interact with each demo.

Quirk 01

Personality Hover — Letters That Behave Like the Sport

Each activity name has its own micro-animation when you hover it. MMA vibrates aggressively. Ski letters glide. Surf bobs in a wave. Snorkel floats gently. Each sport literally moves like itself. Click a tab, then hover the name.

Hover the name ↓
Behaviours
MMA = jitter / Ski = drift / Surf = wave bob / Snorkel = float / Skydive = drop / Scuba = bubble
Effort
~1 hr — split name into spans, per-activity animation profile, rAF loop on hover
Impact
Showstopper — each sport feels different on a physical level

Quirk 02

Type-to-Search

Start typing any letter. The page fuzzy-matches an activity name and switches to it instantly. No tabs to click, no menu to open. Click the demo to focus it, then start typing.

Discoverability

Impact
Power-user — feels like a command palette, rewards typing

Quirk 03

Camera Shake on High-Intensity Switch

Switching to a high-intensity activity (MMA, Skydive) triggers a brief screen shake. Snorkel and Ski switch gently. Subtle but felt. The page reacts physically to what it's showing. Click MMA or Skydive vs Snorkel below.
